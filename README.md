# Burger Order - הזמנת המבורגרים (PWA)

אפליקציית רשת מתקדמת להזמנת המבורגרים בעברית, מותאמת לנייד ולמסך הבית.

## תכונות
- הזמנה מהירה של המבורגרים, תוספות ושתייה
- התאמה אישית של המנה: לחמניה, גבינה, תוספות, רטבים ואקסטרות
- עגלת קניות עם חישוב אוטומטי ודמי משלוח
- שליחת הזמנה בווטסאפ למסעדה
- התקנה למסך הבית (PWA) ועבודה אופליין בסיסית

## קבצים חשובים
- `index.html` – ממשק התפריט, העגלה ותהליך ההזמנה
- `manifest.json` – פרטי האפליקציה לאפליקציית PWA
- `sw.js` – Service Worker לקאשינג והתראות
- תיקיית `icons/` – אייקונים בגדלים שונים

## הגדרות מהירות
עריכת מספר טלפון וקו ווטסאפ ב-`index.html` במקטע CONFIG:

```js
const RESTAURANT = {
  tel: '03-6008820',
  whatsappInternational: '9725XXXXXXXX' // פורמט בינלאומי ללא מקפים
};
```

ניתן לערוך מחירים, קטגוריות ומנות במשתנה `MENU` ובמחירונים במשתנה `PRICES` באותו קובץ.

## פיתוח והרצה מקומית
שירות קבצים סטטי כלשהו (לדוגמה):

```bash
npx serve -l 5173
```

פתחו בדפדפן: `http://localhost:5173`

לבדיקת PWA, הפעילו דרך HTTPS או הדמיית Service Worker בכרום.

## פריסה
- העלו את כל הקבצים לשרת סטטי ב-HTTPS
- ודאו שהנתיב ל-`/sw.js` זמין מהשורש
- עדכנו אייקונים בתיקיית `icons/`

## הערות
- כדי לשנות את שם האפליקציה והצבעים: ערכו את `manifest.json`
- כדי לשנות דמי משלוח/סף משלוח חינם: ערכו את `PRICES` ב-`index.html`
